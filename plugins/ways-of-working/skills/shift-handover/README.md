# shift-handover

Write an on-call or shift handover note from saved incident and alert exports (JSON or CSV) and the outgoing shift's notes: open incidents by age, incidents with no recent update or no owner, noisy alerts and silences or mutes that expire next shift, framed as what is open, what to watch and what is silenced until when, for the incoming on-call.

Not for postmortems or incident timelines (incident-postmortem-timeline), paging people, or silencing alerts.

How Claude runs it, step by step: [SKILL.md](SKILL.md). Everything runs on files you saved; no network.

## Try it

From this folder, on the synthetic files in [examples/](examples/):

```bash
python3 scripts/shift_handover.py examples/incidents.csv --alerts examples/alerts.csv --notes examples/notes.txt --as-of 2026-10-05T08:00:00Z
```
