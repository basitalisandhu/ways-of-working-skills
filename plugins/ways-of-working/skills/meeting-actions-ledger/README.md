# meeting-actions-ledger

Track the action items agreed across project meetings in one ledger, from a folder of Markdown or text notes: each action with its owner and due date, the same action carried over from meeting to meeting merged into one, overdue, unowned and thrice-carried items flagged, every item cited to file and line, written to ledger.md and ledger.json.

Not for calendar access, sending reminder emails, transcribing audio, or judging how people follow up.

How Claude runs it, step by step: [SKILL.md](SKILL.md). Everything runs on files you saved; no network.

## Try it

From this folder, on the synthetic files in [examples/](examples/):

```bash
python3 scripts/meeting_ledger.py examples/notes --as-of 2026-10-12
```
