# working-agreement-check

Check whether repository settings in GitHub match a team's written working agreement (rules such as 'PRs need one review' or 'main is protected') using saved branch protection and rulesets JSON, CODEOWNERS and the workflow list: each written rule met, not met (not enforced) or not checkable, with evidence, and unrecognised rules listed.

Not for audit evidence (github-change-control-evidence), README claims against code (docs-truth-check), or turning on or changing any setting.

How Claude runs it, step by step: [SKILL.md](SKILL.md). Everything runs on files you saved; no network.

## Try it

From this folder, on the synthetic files in [examples/](examples/):

```bash
python3 scripts/working_agreement_check.py examples/agreement.md --protection examples/protection.json --codeowners examples/CODEOWNERS --workflows examples/workflows.json
```
