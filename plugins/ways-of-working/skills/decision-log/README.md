# decision-log

Record operational decisions as one Markdown file each (context, decision, who decided, date, review date, status, supersede links) and lint the folder for overdue reviews, broken or one-way supersede links, cycles and missing fields, rendering an INDEX.md table.

Not for design choices with options and trade-offs (adr-writer), recovering old decisions from git history (adr-miner), choosing between options, or risk registers (risk-register-refresh).

How Claude runs it, step by step: [SKILL.md](SKILL.md). Everything runs on files you saved; no network.

## Try it

From this folder, on the synthetic files in [examples/](examples/):

```bash
python3 scripts/decision_log.py examples/decisions --as-of 2026-10-05
```
