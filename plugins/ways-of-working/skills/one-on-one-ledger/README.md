# one-on-one-ledger

Prepare for 1:1s (one to one or one-on-one catch-ups) from your own local notes: days since the last 1:1 against a cadence, open commitments on each side (what you promised first, overdue marked) and topics that keep coming up, as a ledger per person or a prep sheet for one.

Not for performance reviews, ratings, rankings, sentiment or comparing people, notes in a shared drive or repository (the script refuses those paths), or sending anything to anyone.

How Claude runs it, step by step: [SKILL.md](SKILL.md). Everything runs on files you saved; no network.

## Try it

From this folder, on the synthetic files in [examples/](examples/):

```bash
python3 scripts/one_on_one_ledger.py examples/notes --as-of 2026-10-05 --allow-shared
```

`--allow-shared` is needed only because the examples live inside this repository; the script refuses notes in a repository or shared folder unless told otherwise.
