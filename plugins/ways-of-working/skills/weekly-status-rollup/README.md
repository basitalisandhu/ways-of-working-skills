# weekly-status-rollup

Write one lead's weekly update from saved git log text, gh pr and issue list JSON and last week's note: shipped, in review, in progress, blocked and carried over with weeks carried, plus Decisions needed and Risks left for the author, never invented; a daily mode gives a standup update from yesterday's commits.

Not for team sprint metrics (iteration-report), the review queue (pr-queue-digest), ranking people by output, or repositories you cannot export.

How Claude runs it, step by step: [SKILL.md](SKILL.md). Everything runs on files you saved; no network.

## Try it

From this folder, on the synthetic files in [examples/](examples/):

```bash
python3 scripts/weekly_status_rollup.py --git-log shop=examples/shop.log --prs examples/prs.json --issues examples/issues.json --last-week examples/last-week.md --as-of 2026-10-01
```
