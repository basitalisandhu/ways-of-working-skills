# vendor-scorecard

Compare vendors, tools or suppliers on agreed weighted criteria from a CSV (criterion, weight, a 1 to 5 score column per vendor): weighted scores and ranking, which one wins, whether the winner changes when each weight moves one step, ties for first, data problems, and a Markdown scorecard with a blank decision line.

Not for choosing the criteria, pricing negotiation, or security questionnaires and vendor evidence (compliance-evidence-skills).

How Claude runs it, step by step: [SKILL.md](SKILL.md). Everything runs on files you saved; no network.

## Try it

From this folder, on the synthetic files in [examples/](examples/):

```bash
python3 scripts/vendor_scorecard.py examples/scores.csv
```
