# focus-plan

Find focus time in a meeting-heavy week from a saved .ics calendar export (Outlook, Google Calendar or Apple): meetings and hours per day, back-to-back runs, the longest free blocks inside working hours for deep work, recurring series with counts, and a plain focus plan; recurring rules it cannot expand are listed, never guessed.

Not for changing a calendar, reading mail or meeting content, or deciding which meetings to decline.

How Claude runs it, step by step: [SKILL.md](SKILL.md). Everything runs on files you saved; no network.

## Try it

From this folder, on the synthetic files in [examples/](examples/):

```bash
python3 scripts/focus_plan.py examples/week.ics --start 2026-10-05 --tz UTC
```
