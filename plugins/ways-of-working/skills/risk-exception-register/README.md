# risk-exception-register

Review a register of time-bound security exceptions, waivers and risk acceptances (CSV or Markdown table): flags expired exceptions and those that expire in the next 30 days, missing approvers or compensating controls, approvers who signed off their own request, and repeated renewals, then prints a review agenda with a blank decision line per item.

Not for user access reviews, deciding whether a risk is acceptable, scoring risk, or Vanta and other GRC tool integration.

How Claude runs it, step by step: [SKILL.md](SKILL.md). Everything runs on files you saved; no network.

## Try it

From this folder, on the synthetic files in [examples/](examples/):

```bash
python3 scripts/exception_register.py examples/exceptions.csv --as-of 2026-10-05
```
