# rfc-lifecycle

Draft a design proposal (RFC or design doc) with a fixed section list and a security review checklist, then lint a folder of RFCs for the status header, review questions with no answer, open questions left in review or accepted RFCs, a missing decision date or section, and RFCs stuck in review over 14 days.

Not for architecture decision records (adr-writer once accepted), choosing the design, or replacing the review itself.

How Claude runs it, step by step: [SKILL.md](SKILL.md). Everything runs on files you saved; no network.

## Try it

From this folder, on the synthetic files in [examples/](examples/):

```bash
python3 scripts/rfc_lint.py examples/rfcs --as-of 2026-10-05
```
