# change-request-writer

Write a CAB-style change record (change request or change ticket) for an infra change from a saved terraform show -json plan or a PR (gh pr view export): counts to add, change, destroy and replace, IAM, security group, KMS, S3 policy and network changes flagged for a reviewer, a risk tier by a stated rule, rollback and verification steps, and who needs to approve.

Not for approving changes, running terraform, reviewing the Terraform code, or ServiceNow and Jira integration.

How Claude runs it, step by step: [SKILL.md](SKILL.md). Everything runs on files you saved; no network.

## Try it

From this folder, on the synthetic files in [examples/](examples/):

```bash
python3 scripts/change_request.py examples/plan.json --change-id CHG-1042 --window "Sat 02:00 to 04:00 UTC"
```
