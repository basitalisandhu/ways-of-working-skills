# next-actions-sweep

Turn saved exports of emails and chats from several inboxes (Microsoft Graph mail and Teams JSON, Slack export, CSV; work and personal accounts together) into one ranked do-next list: each message labelled reply, decide, do or FYI with the reason, any stated deadline and the source link, duplicates across accounts merged, and what is waiting on you versus waiting on others.

Not for sending, drafting or filing mail, live connector access, or meeting actions (meeting-actions-ledger).

How Claude runs it, step by step: [SKILL.md](SKILL.md). Everything runs on files you saved; no network.

## Try it

From this folder, on the synthetic files in [examples/](examples/):

```bash
python3 scripts/next_actions.py --source work-mail=examples/work-mail.json --source home-mail=examples/home-mail.json --source teams=examples/teams.json --source slack=examples/slack.json --source other=examples/other.csv --me alex.morgan@example.com --me alex@example.org --me "Alex Morgan" --me U0ME --me u-alex --vip priya.shah@example.com --as-of 2026-10-16T09:00:00Z
```
